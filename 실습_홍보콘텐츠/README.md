# 홍보 콘텐츠 실습: 판결 하나 → 블로그 글·쇼츠 원고·영상

실제 판결 하나로 핸드아웃 7절의 지시문 1~8번을 순서대로 해 보는 폴더입니다.

| 파일 | 내용 |
|---|---|
| `판결_대법원_2022도5937_상관모욕.md` | 대법원 2026. 7. 22. 선고 2022도5937 전원합의체 판결(상관모욕) 전문. 국가법령정보센터 판례 API에서 받은 문구 그대로입니다. 판결은 저작권법 제7조 제3호에 따라 저작권 보호 대상이 아닙니다 |
| `바로시험_영상/cuts.json` | 이 판결로 미리 만든 8컷 컷시트. 원고 단계를 건너뛰고 영상 조립만 먼저 시험할 때 씁니다. 컷마다 `source`에 판결의 근거 위치를 적었습니다 |

## 순서

1. Claude Code에서 이 폴더(`실습_홍보콘텐츠`)를 「폴더 추가」로 엽니다.
2. 핸드아웃 7절 1번 지시문의 ( ) 안을 `판결_대법원_2022도5937_상관모욕.md`로 바꿔 넣습니다. 결과는 `promo/주제/` 폴더에 쌓입니다.
3. 2~5번(쇼츠 원고·사실 대조표, 컷시트, SNS 글, 광고 점검)을 차례로 시킵니다.
4. 영상은 6번(환경 점검)부터 합니다. 처음에는 `바로시험_영상`으로 무료 시험(macOS 내장 음성 + 회색 자리표시 그림)을 해 보고, 그다음 7번 또는 8번으로 4번에서 만든 컷시트를 영상으로 만듭니다.

## 주의

- 그림·음성 생성은 Gemini 또는 OpenAI API 키가 있어야 하고, 사용량만큼 요금이 나옵니다. 스킬이 생성 전에 컷 수를 보여 주고 승인을 받습니다.
- 실습 결과물을 실제로 게시하려면 변호사 광고 규정 점검(7절 5번)과 유튜브 AI 사용 공개를 먼저 합니다.
- `cuts.json`의 문장은 강사가 판결과 대조해 만든 예시입니다. 게시용으로 그대로 쓰지 말고 직접 만든 사실 대조표로 다시 확인합니다.
